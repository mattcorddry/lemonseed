# Lemonseed brand mark

Canonical lemon mark used in the shell, setup, and installer UIs.

- **Preferred source:** https://lemonseed.ai/lemon.jpg
- Regenerate derivatives: `python3 scripts/generate-brand-icons.py` (needs Pillow)

Packaged copies live under `control-plane/static/brand/` and `installer/static/brand/`
(icon sizes only — not the multi-MB master PNG).
